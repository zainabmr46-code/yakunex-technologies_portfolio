
# Project Requirements

## Project Name
Yakunex Technologies – Company Portfolio Website

## Project Type
Individual Internship Practical Assessment

## Project Overview
The purpose of this project is to develop a professional, responsive company portfolio website for Yakunex Technologies (Pvt) Ltd. The website introduces the company, presents its services and capabilities, showcases project examples, and provides a way for visitors to contact the company.

## Target Users
- Potential clients looking for IT services and solutions.
- Businesses interested in technology and outsourcing services.
- Internship and job seekers interested in the company.

## Functional Requirements

### Public Website
- Display the company introduction.
- Present the company's vision, mission, and core values.
- Display the available services.
- Show project examples on the Projects page.
- Display technology-related articles on the Articles page.
- Provide a contact form for submitting enquiries.
- Provide navigation between Home, Projects, Articles, and Contact pages.

### Administrator Area
- Allow an administrator to log in.
- Display submitted contact enquiries.
- Allow the administrator to review enquiry details.
- Allow the administrator to update enquiry statuses.
- Allow the administrator to delete enquiries.
- Send an email notification when a supported enquiry status update occurs.

## Non-Functional Requirements
- Responsive design for desktop, tablet, and mobile screens.
- User-friendly navigation and professional UI.
- Form validation and error handling.
- Secure administrator authentication.
- Reliable database storage of enquiries.
- Maintainable frontend and backend code.

## Main Technologies
- React
- Vite
- Tailwind CSS
- Laravel
- PHP
- MySQL

## Project Scope
The project includes the public company website, contact enquiry functionality, database integration, and administrator enquiry management.
